# TraceBack — Evidence Folder

Place genuine screenshots captured from the running project and pgAdmin in this folder.

## Required screenshots

Use these filenames to keep the submission organized:

1. `01-dashboard.png` — React dashboard open in the browser.
2. `02-report-submission.png` — successful report submission in the frontend.
3. `03-reports-table.png` — pgAdmin query showing the submitted report in PostgreSQL.
4. `04-audit-logs.png` — pgAdmin query showing the trigger-generated audit log.
5. `05-api-health.png` — browser or terminal showing GET /api/health success.
6. `06-api-reports.png` — GET /api/reports response.
7. `07-api-matches.png` — GET /api/matches response.
8. `08-database-tables.png` — pgAdmin showing the 12 project tables.
9. `09-indexes.png` — pgAdmin showing the eight indexes.
10. `10-sql-queries.png` — screenshots of actual SQL query executions and outputs.

## Capture instructions

- Capture screenshots directly from your own browser, terminal, and pgAdmin.
- Do not edit outputs or create illustrative screenshots that could be mistaken for actual execution evidence.
- Avoid including passwords, access tokens, personal contact details, or other secrets.
- Upload the screenshots to this folder using GitHub's Add file → Upload files option, or commit them from the local repository.

Only mark an item complete after its screenshot has been uploaded.
